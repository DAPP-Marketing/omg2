# OMG株式会社 コーポレートサイト

Astro、Tailwind CSS v4、TypeScript で構築した静的優先のコーポレートサイトです。

## 開発コマンド

```bash
pnpm install
pnpm run dev
pnpm run build
```

## 情報の更新場所

会社情報、事業内容、お知らせ、募集情報、ナビゲーションは `src/data/` にまとめています。情報を変更するときは、各ページを直接編集せず、まず対応するデータファイルを更新してください。

## 公開前に必要な作業

- 正式な車両・倉庫・拠点・代表者写真への差し替え
- お問い合わせフォームの送信先と Cloudflare Workers 処理の設定
- 個人情報保護方針ページまたはURLの確定
- 各募集条件の最新情報の最終確認

詳細な制作・更新ルールは `AGENTS.md` を参照してください。
