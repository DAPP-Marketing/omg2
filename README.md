# OMG株式会社 採用サイト「梅プラン」

Astro、Tailwind CSS v4、TypeScript で構築した静的優先の採用サイトです。

## 開発コマンド

```bash
pnpm install
pnpm run dev
pnpm run build
```

## 情報の更新場所

会社情報・募集職種・募集条件・FAQ・ナビゲーションは `src/data/` にまとめています。給与や勤務時間などを変更するときは、各ページを直接編集せず、まず対応するデータファイルを更新してください。

## 公開前に必要な作業

- 正式なスタッフ・車両・倉庫・代表者写真への差し替え
- 応募フォームの送信先と Cloudflare Workers 処理の設定
- 個人情報保護方針ページまたはURLの確定
- 各募集条件の最新情報の最終確認

詳細な制作・更新ルールは `AGENTS.md` を参照してください。
